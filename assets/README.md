# Pathey Boot Assets Folder

Place your boot animation media file in this folder!

Supported files:
- `boot_animation.mp4` (Recommended: High-definition MP4 video)
- `boot_animation.webm` (WebM video)
- `boot_animation.gif` (Animated GIF)
- `boot_animation.png` (Static image logo/graphic)

When Pathey launches, it will automatically detect and play your animation file during the startup sequence!
